*pdfpreview.txt*  Continuous PDF reading in Neovim

INTRODUCTION                                             *pdfpreview*

pdfpreview.nvim displays local PDFs inside Neovim using Kitty graphics.
It requires Neovim 0.11+, Poppler (pdfinfo, pdftoppm and pdftotext), termguicolors,
and a terminal supporting Unicode image placeholders and local files.
Use :set mouse=a for scrolling and selection. SSH and multiplexers are not
supported.

On macOS, run `make native` in the plugin directory to build the Core Graphics
helper. Rebuild after updating native source. The automatic rasterizer falls
back to Poppler if the helper is unavailable, incompatible or fails.

COMMANDS                                                 *pdfpreview-commands*

:PdfOpen [file]                                           *:PdfOpen*
        Open a PDF, or use the current file path when omitted. Paths with
        spaces do not need quotes. setup({ auto_open = true }) also handles
        :edit document.pdf. Avoid registering another PDF BufReadCmd handler.
:PdfZoom {percent}                                        *:PdfZoom*
        Set zoom relative to fit width. 100 fits the widest page to the
        window. Decimal percentages are accepted. Default range: 10-800.
:PdfPage {number}                                         *:PdfPage*
        Jump to the given page (starting at 1).
:PdfCopy                                                  *:PdfCopy*
        Copy selected PDF text to the system clipboard (+ register).
        If no clipboard provider is available, keep it in the unnamed register.
:PdfTranslate                                            *:PdfTranslate*
        Translate selected PDF text in a floating window.
        See |pdfpreview-translation|.
:PdfReload                                               *:PdfReload*
        Reload the current document from disk.
:PdfStats                                                *:PdfStats*
        Report render paths, target/displayed zoom, cache usage, active work,
        refinement state, cell dimensions and fallback reasons. Input timing
        ends at frame submission; it excludes terminal transfer and physical
        display delay.
:PdfClose                                                *:PdfClose*
        Close the reader and release its workers and temporary files.

Run :checkhealth pdfpreview to check dependencies and terminal identification.

MAPPINGS                                                 *pdfpreview-mappings*

Left click/drag   Select characters or a range of PDF text (words with Poppler).
Double-click      Select a whole word.
y / "ay           Copy selected text to the unnamed / named register.
Ctrl-C / Cmd-C    Copy to the system clipboard (when forwarded by the terminal).
Right click       Open Copy / Translate menu.
Escape            Clear text selection.
j/k, Up/Down       Scroll one row; counts supported.
h/l, Left/Right    Pan horizontally; counts supported.
Ctrl-D / Ctrl-U    Scroll most of the viewport (also PageDown / PageUp).
+ / = / -         Zoom in / out.
0                 Fit width.
gg / G            Start / end of document.
[count]G          Jump to a page.
R                 Reload.
q                 Close.

Wheel events scroll continuously across page boundaries. Ctrl-wheel zooms
when forwarded by the terminal. True pinch-to-zoom is not supported.

TEXT SELECTION                                           *pdfpreview-selection*

Drag across text, then press y to yank or Ctrl-C to copy. Double-click selects
a whole word. Hold the button and scroll to extend across pages. Selection
stays attached to PDF coordinates through zooming, scrolling and resizing.
The surface renderer composites blue highlights into the PDF pixels, so
they follow scrolling, refinement and sidebar resizing. Other renderers
temporarily hide highlights while an overlapping floating window or command
line is open; copying and the logical selection remain available.

Text extraction is lazy and independent of the rasterizer. With the macOS
helper built, PDFKit supplies character ranges and bounds. Combining marks
and emoji remain together. Terminal mouse positions still use cells; zoom in
to select small letters more precisely. Copying waits for pending extraction.
No OCR is performed: scanned pages without a text layer cannot be selected.
Extracted spaces, line breaks and reading order are retained; complex columns
or encodings may affect that order.

text_backend = "auto" prefers PDFKit, falling back to Poppler word selection
if unavailable. Rebuild older helpers with make native. "pdfkit" requires the
macOS helper; "poppler" always uses pdftotext. :PdfStats reports the active
text backend and any fallback reason. Without either extractor, selection is
unavailable but rendering still works.

Lua API: require("pdfpreview").copy(register) copies the current selection;
the default register is "+". A ready selection returns the copied string,
otherwise copying completes asynchronously. clear_selection() removes it.

TRANSLATION                                              *pdfpreview-translation*

Right-click selected text and choose Translate, or use :PdfTranslate. Without
an existing selection, right-clicking a word selects it first. Click outside,
press q or Escape to close the menu/result without closing the PDF. Translation
runs asynchronously; closing the float cancels pending work.

The default translates English to Simplified Chinese using Google's free web
endpoint and falls back to MyMemory for short selections (up to 500 UTF-8
bytes). curl and internet access are required; no account/API key is needed.
Only choosing Translate sends selected text to the service(s). Opening the
menu, selecting and copying remain local. Free endpoints may be unavailable
or rate-limited; errors appear in the float. Up to 32 results are cached in
memory. Selections above 5000 bytes are rejected without truncation.

Options (within setup's translation table):
>
    translation = {
      provider = "google", -- or "mymemory"
      source = "en",
      target = "zh-CN",
      fallback = true,     -- MyMemory after a Google failure
      timeout = 10,        -- seconds per service, 1-60
    }
<
source="auto" works with Google but disables MyMemory fallback, since MyMemory
requires an explicit source language. Lua API: require("pdfpreview").translate().

OPTIONS                                                  *pdfpreview-options*

Call require("pdfpreview").setup({ ... }) once during initialization.
Defaults are shown below. Zoom values are factors, not percentages.

auto_open = false          Register a PDF BufReadCmd handler.
renderer = "auto"          "auto", "surface", "viewport" or "unicode".
rasterizer = "auto"        "auto", "native" (macOS) or "poppler".
native_renderer = nil      Optional absolute path to the compiled helper.
pdfinfo = "pdfinfo"        Poppler metadata executable.
pdftoppm = "pdftoppm"      Poppler rendering executable.
pdftotext = "pdftotext"    Poppler text extraction executable.
text_backend = "auto"     "auto", "pdfkit" (macOS characters), "poppler" (words).
scroll_step = 1            Rows per wheel event.
scroll_animation_ms = 40   Surface movement interpolation (0-200 ms).
surface_refine_ms = 100    Idle detail redraw delay (0-2000 ms).
surface_refine_scale = 2   Idle pixel density multiplier (1-2).
zoom_step = 1.15           Relative zoom multiplier for +/- and Ctrl-wheel.
min_zoom = 0.1             Minimum zoom relative to fit width.
max_zoom = 8               Maximum zoom relative to fit width.
page_gap = 2               Gap between pages in terminal rows.
max_dimension = 4096       Cached page edge limit in pixels.
cell_width = nil           Automatic width; a positive number overrides it.
cell_height = nil          Automatic height; a positive number overrides it.

The following options apply to tile/Unicode rendering:

cache_pages = 8            Soft limit on cached page/tile renders.
image_cache_bytes = 16777216
                          Soft budget for terminal images (16 MiB).
jobs = 2                  Maximum concurrent raster jobs.
prefetch_zoom = true       Predict source tiles for the next zoom level.
progressive_zoom = true    Reproject complete cached coverage during zoom.
compact_placeholders = false
                          Experimental compact coordinate encoding. Leave
                          false for reliable clipping; floats force false.

Set scroll_animation_ms=0 for immediate movement with fewer intermediate
frames. Set surface_refine_scale=1 to reduce idle CPU, memory and transfer
costs while keeping direct PDF redraws at native terminal pixel density.
Set surface_refine_ms=0 to disable idle redraws, losing detail at high zoom.
Set prefetch_zoom=false to reduce speculative tile work.

CELL SIZE                                               *pdfpreview-cell-size*

By default, terminal pixel and grid dimensions are read from the system with
TIOCGWINSZ. The plugin tries stdout, stdin, then stderr, skipping descriptors
without valid pixel dimensions. It divides total pixels by columns/rows to
derive the cell size. If detection is unavailable, it uses 9 x 18 pixels.

Detection is refreshed on resize, UI attachment, focus gain and drawing.
Changed dimensions rebuild the layout while preserving the approximate
viewport-center reading position. There is no background polling; gaining
focus with unchanged effective dimensions does not trigger rendering.

The terminal interface returns ONLY INTEGER pixel measurements. Otty can
round cell dimensions before reporting totals. Division may produce a
fractional average, but cannot recover precision already lost by the
terminal. Automatic correction cannot guarantee exact proportions; accurate
fractional calibration still requires manual cell_width/cell_height values.

Both overrides accept finite positive numbers, including fractions, in
physical pixels. Each axis independently takes precedence over detection.
For a known square whose displayed width is W and height is H, keep the
current cell height and use:
>
    new_cell_width = current_cell_width * W / H
<
For example, a width of 15 with a square measuring 520 x 500 suggests 15.6.
Add cell_width = 15.6 to your plugin options and restart Neovim. This example
is not an Otty default; it depends on your font, font size and display scale.
Recalibrate after changing these settings. Remove either override (nil) to
restore automatic detection for that axis.

:checkhealth pdfpreview shows detected/effective dimensions and the source
for each axis. :PdfStats reports cell_width/cell_height used by the reader,
cell_width_source/cell_height_source (ioctl, manual or fallback), and
detected_cell_width/detected_cell_height when a terminal report is available.

RENDERING                                               *pdfpreview-rendering*

Automatic selection uses the surface compositor in Otty with Neovim 0.12+
and a unified-memory Metal device. Other Otty sessions use viewport tiles;
other terminals use whole-page Unicode placements. Otty has been visually
tested on macOS. Kitty and Ghostty remain unverified protocol targets.

Surface motion transforms cached pages at fractional pixel positions. After
input settles, a separate worker redraws visible PDF text and paths at up to
twice the terminal pixel density on each axis, preserving the same cell grid.
The effective multiplier decreases to stay within 16,777,216 output pixels
and 8192 pixels per dimension. PdfStats reports refinement_scale, cell_width
and cell_height. max_dimension limits cached pages, not direct PDF redraws.
New motion cancels outdated refinement work. Dragging and clearing selections
reuse the clean final-resolution viewport without downgrading to motion pixels.
The terminal receives raster images; embedded bitmaps retain their source
detail limits.
Discrete wheel input is interpolated; native fractional input is not received.

Native CPU/GPU source caches share a 128 MiB limit. Two reusable output
generations have a separate 64 MiB mapping limit. One refinement viewport
brings temporary output files to at most 128 MiB. A separate clean refinement
cache for selections retains at most 64 MiB. Process memory includes
additional document, framework and staging allocations.

Surface motion output is limited to 8,388,608 pixels, 8192 per dimension,
256 terminal rows and 16 visible pages. Oversized views, compositor errors or
missing terminal read acknowledgments fall back to viewport tiles.

Viewport tiles reuse pixels across scrolling and nearby zoom levels.
Unicode rendering caches whole pages. Visible/in-flight images may exceed
soft cache limits. Large zoom levels can be softer because raster sizes are
capped. Zoom and resize preserve the approximate viewport-center position.

Hiding a reader releases terminal images and stops refinement; closing stops
all workers and removes temporary files after they exit. PDFs remain local.
PDF buffers disable Snacks scroll animation to keep image rows aligned.

Only one viewport is maintained per document buffer. OCR, search, links,
annotations, outlines, SyncTeX and passwords are not supported.

See README.md for installation, Snacks configuration and development tests.
